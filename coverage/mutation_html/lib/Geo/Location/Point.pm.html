  341: =head2	attr
  342: 
  343: Get or set arbitrary attributes, such as city or country.
  344: A call with an argument sets the attribute and returns the value that was set;
  345: a call without one reads it back and returns C<undef> if it was never set.
  346: 
  347:     $location->city('London');
  348:     $location->country('UK');
  349:     print $location->as_string(), "\n";
  350:     print "$location\n";	# Calls as_string
  351: 
  352: It is the argument list, not the value, that decides whether a call is a read or a write,
  353: so false values are attributes like any other and are stored and returned unchanged:
  354: 
  355:     $location->confidence(0);
  356:     print 'matched: ', defined($location->confidence()) && $location->confidence(), "\n";
  357: 
  358: The upper case variant of the key is consulted
  359: (but not overwritten) when the key as given has never been set,
  360: which is how the MaxMind field names are read. An attribute that has been set,
  361: however false, takes precedence over it.
